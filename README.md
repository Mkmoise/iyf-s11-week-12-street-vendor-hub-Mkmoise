## Project Description

Street Vendor Hub is a full-stack web application designed to connect users with local street vendors and their businesses.

The platform allows users to browse vendors, view vendor details, and interact with vendor-related content. It also includes user authentication, advertisements, and reviews.

The project was developed as a collaborative team project using React for the frontend, Node.js and Express for the backend, and MongoDB for database management.
