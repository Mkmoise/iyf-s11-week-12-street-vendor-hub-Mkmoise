The team followed a feature-branch workflow:

2. Implement the assigned functionality
3. Commit changes
4. Push the branch to GitHub
5. Create a Pull Request
6. Request a teammate review
7. Resolve conflicts if necessary
8. Merge the Pull Request into `main`
9. Perform final testing
